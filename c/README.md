The kernels this repository's Rust crate builds (`build.rs`): the x86-64
assembly for SSE4.1, AVX2, and AVX-512, the AArch64 integer + NEON hybrids
(`blake3_neon_hybrid_aarch64.S`, generated by `tools/gen_neon_hybrid.py`),
the SME2 kernels, and the C NEON kernel for AArch64 CPUs without the SHA-3
extension (with the two headers it includes). C programs use official
BLAKE3's C library.
